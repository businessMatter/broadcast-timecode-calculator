- 无论最终能否抵消，Calculate 任一中间值超出安全整数即报错。
- 列表制表符在 trim 前检查，空白行保留物理行号；无效项不输出部分总和。
- 拒绝 Expression 多行粘贴时，保持原始输入并清除旧结果；直到编辑或切换输入方式才解除。
- Round 的实际变化量展示带符号完整时间码，包含对齐产生的变化。

- 长预览单元格使用内部滚动；长结果先独占一行，页面保留自然纵向滚动。
- 未完成输入使用中性提示；全部 Calculate 错误项在预览折叠之外列出。

## 发布前人工验收清单

1. 默认 Reformat 空输入、Copy 禁用；刷新仍回到 Reformat，帧率/输出偏好恢复，输入清空。
2. 依次输入 `04.31.00` 和 `04:31:00`，核对预览差异；批量粘贴带描述的行与 Markdown 表格，确认只输出每行开头的时间码。加入无效行 `01:75`，确认按物理行号报错并阻断全部输出；输入 `00.39.10` 切换 mm:ss 后切回，帧仍为 10。
3. Round `00:00:44:00`、+10、5、Up 得 `00:00:55:00`；`00:00:05:12` 得 `00:00:20:00`。None 禁用并忽略非法 Interval。
4. Duration `0:44` → `1:20` 得 36 秒；打开 Include end frame 后多 1 帧。End 早于 Start 时应报错并阻断结果。
5. Calculate 粘贴产品 spec 的三项表达式得 `11:34:26:02`；`00:10 − 00:20` 得 `-00:00:10:00`。列表三行 `04:12`、`00:12:00:12`、`01:02:03` 得 `01:18:15:12`。
6. 输入含空行、bad、行尾 Tab；任一无效项阻断结果，错误行号正确。多于 5 项时仍可定位所有错误，并用键盘激活错误按钮选中原文。
